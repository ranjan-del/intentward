# ADR 0001: Record architecture decisions

Status: accepted (2026-10-02)

## Context

Significant decisions in a research system get forgotten or silently reversed.

## Decision

Every significant architectural decision gets a short ADR in docs/adr/ with context, decision and consequences. An ADR is superseded by a new ADR, never edited away.

## Consequences

Decisions stay traceable to the evidence that motivated them.
