# ADR 0002: Name the project IntentWard

Status: accepted (2026-10-02)

## Context

The working name AgentOS is generic and heavily used. "Agent mandate" is taken by several small repositories with nearly the same pitch, by Google's AP2 "intent mandate" term, and on PyPI. Sanskrit and plain dictionary words were ruled out by the owner. Candidates checked on 2026-10-02 against GitHub and PyPI: IntentOS, IntentGate, AgentWard, AgentFence, HarnessOS, ScopeOS and others were all in use.

## Decision

Name the project **IntentWard**: intent plus ward (to guard; a protected zone). Repository `ranjan-del/intentward`, Python package `intentward`, CLI `intentward`. The name had no GitHub repository and was free on PyPI when checked.

## Consequences

The name states the thesis: the agent's world is guarded by the user's intent. The PyPI name should be reserved before the first release.
